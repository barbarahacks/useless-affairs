# department of useless affairs 🏛️

submit your most pointless request. it gets routed to the departments relevant to it. most will say no. built for the stupid ideas hackathon (ottawa).

see [FEATURES.md](FEATURES.md) for what we are working on.

## run it

```sh
npm install
npm run dev      # local dev server
npm run build    # typecheck + production build into dist/
```

handy urls while developing:

- `/?fast` skips animations and sound.
- `/?req=can%20i%20blink` auto-runs a request.
- `/?fast&req=can%20i%20blink` does both, which is good for screenshots.
